# DPNMP
Data processing app new member project for Bruin Baja Racing
Before running:
Use `python -m pip install pandas` or `conda install pandas` if you are using conda

# Troubleshooting:
if you install pandas and python is still giving you errors, either install conda and run the script using conda,
or run `python -c "import pandas, sys; print(sys.executable)"` to get the path to pandas
then, in VSC hit `Ctrl + Shift + P` and type `Python: Select Interpreter` and change your interpreter path to the path given by the python command
